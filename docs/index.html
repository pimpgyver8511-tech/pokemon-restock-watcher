🔑 Zugang einrichten

Die Seite steuert den Watcher über die GitHub-API. Dafür brauchst du einmalig einen Fine-grained Personal Access Token. Er wird nur in diesem Browser gespeichert.

So erstellst du den Token (2 Minuten)
  1. github.com/settings/personal-access-tokens/new öffnen
  2. Name z. B. „Pokémon-Watcher UI“, Ablaufdatum nach Wunsch
  3. Repository access: „Only select repositories“ → pokemon-restock-watcher
  4. Permissions → Repository: Actions = Read and write, Variables = Read and write
  5. „Generate token“ → Token kopieren und hier einfügen

▶️ Manuell starten

Ein manueller Abruf prüft sofort, unabhängig von Intervall und Zeitfenster, und dauert etwa 1–2 Minuten. Ist etwas im Preisbereich verfügbar, kommt direkt eine Mail.

⚙️ Abrufzeiten & Benachrichtigung

„Aktiv von 0 bis 24 Uhr“ = rund um die Uhr. Über Mitternacht geht auch, z. B. 22 bis 7 Uhr. Alle Zeiten in deutscher Zeit.
